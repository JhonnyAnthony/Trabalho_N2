# Lumina Tech Solar

**Economize até 95% na conta de luz com energia solar inteligente!**

Lumina Tech Solar é um site informativo e interativo sobre economia de energia através de sistemas solares inteligentes. O projeto apresenta os benefícios, funcionamento, depoimentos reais e um formulário para solicitar orçamento personalizado.

## 🚀 Funcionalidades
- **Simulação de economia**: Descubra como reduzir drasticamente sua conta de energia.
- **Monitoramento em tempo real**: Controle sua produção e consumo pelo app.
- **Solicitação de orçamento**: Formulário simples e rápido para receber uma proposta sob medida.
- **Depoimentos reais**: Veja resultados de clientes residenciais e comerciais.
- **Benefícios claros**: Economia, segurança, sustentabilidade e gestão pelo app.
